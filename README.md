# Attendance Management System

## Developed by Yanet Yeshiwas

### Overview

The Attendance Management System is a desktop application built using **Python**, **CustomTkinter**, and **SQLite**. It helps educational institutions efficiently manage student attendance records through a simple and user-friendly interface.

---

## Features

### Admin Module

* Secure admin login
* Add new students
* Delete student records
* Generate attendance reports
* Export reports to CSV

### Student Module

* Select student name
* Mark attendance
* Record attendance status:

  * Present
  * Late
  * Absent

### Reporting

* View attendance records by date range
* Export attendance reports to CSV format

---

## Installation

### Install Required Packages

```bash
pip install customtkinter
pip install tkcalendar
pip install pandas
```

### Run the Application

```bash
python app.py
```

---

## Database

The system uses **SQLite** and automatically creates:

* Students Table
* Attendance Table
* Admin Table

**Default Admin Password:** `admin123`
